## 🌟 Princípios Fundamentais

### 1. User-Centric
Tudo começa com o utilizador. Validar assumptions antes de construir.

### 2. Data-Informed
Decisões baseadas em dados, não em opiniões. Mas dados servem para informar, não para ditar.

### 3. Iterativo
Build → Measure → Learn. Ciclos rápidos de feedback.

### 4. Outcome-Focused
Focar em outcomes (resultados), não outputs (entregas).

### 5. Transparent
Comunicação clara e constante com todos os stakeholders.

## 📖 Conceitos-Chave

### Product-Market Fit
O grau em que um produto satisfaz forte demanda de mercado.
**Indicadores**: Retention > 40%, Word-of-mouth orgânico, Difficult to replace

### Jobs-to-be-Done (JTBD)
Framework que foca no "trabalho" que o utilizador está a tentar realizar.
**Formato**: "Quando [situação], quero [motivação], para [resultado esperado]"

### Minimum Viable Product (MVP)
A versão mais simples do produto que permite validar hipóteses com utilizadores reais.
**Não é**: Produto de baixa qualidade
**É**: Produto focado nas funcionalidades essenciais

### North Star Metric
A métrica única que melhor captura o core value entregue aos utilizadores.
**Exemplos**: 
- Airbnb: Noites reservadas
- Facebook: Daily Active Users
- Spotify: Time spent listening
